How web browsers developed

Web browsers developed alongside the World Wide Web. In 1989, Tim Berners-Lee proposed the Web at CERN to help researchers share information. By late 1990, he built the first web server and browser, called WorldWideWeb.

CERN and the early Web

The first browser was developed on a NeXT computer and allowed people to follow links between documents. In April 1993, CERN made the World Wide Web technology available on a royalty-free basis. This allowed people to use and develop the technology without paying licence fees (CERN, n.d.).

Mosaic: images alongside text

Mosaic was released in 1993 when Marc Andreessen and Eric Bina developed NCSA Mosaic. By displaying images alongside text, Mosaic helped make the Web easier to use and more popular (NCSA, n.d.).

Netscape & The Browser Wars

Netscape Navigator followed in 1994, and quickly became popular. Its competition with Microsoft's Internet Explorer became known as the "browser wars". During this period, browsers added features and support for technologies such as JavaScript and CSS (Mozilla, n.d.).

Did You Know?

JavaScript was created in just 10 days in May 1995 by Brendan Eich at Netscape Communications. It was initially named Mocha, then LiveScript, and finally renamed JavaScript to link its name with the popularity of Java.

HTML, CSS and JavaScript

HTML gives a page its structure and content. CSS changes how it looks. JavaScript makes it respond to actions such as clicking a button. 

// Citation: Class toggle adapted from W3Schools JS classList:

Getting data and updating a page

The fetch() function gets data from an API. JavaScript can then use document.createElement() to add elements and textContent to display the results without reloading the page. 

// Citation: Fetch API async/await pattern adapted from W3Schools:
async function loadData(url) {
    const res = await fetch(url);
    const data = await res.json();
    return data;
}
Using let and const

Use let when a variable needs to be reassigned and const when it does not. Both are limited to the block where they are declared, such as the code inside an if statement. 

const APP_NAME = "WebTech";
let userCount = 42;
